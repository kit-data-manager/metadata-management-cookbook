# Editing an existing Crate

**Description**:

This recipe guides you through opening and modifying an existing RO-Crate using NovaCrate.

**Ingredients**:

- Existing RO-Crate: this can be your own RO-Crate or one created by following the [**Creating a new Crate**](recipe-create-new-crate.md) recipe.
- Access to the NovaCrate web application
- Web browser

**Steps**:

1. Open the [NovaCrate](https://novacrate.datamanager.kit.edu/editor) web application.
2. If your RO-Crate is already listed under **Local RO-Crates**, click **Open**.
3. Otherwise, click **Import RO-Crate** and select the RO-Crate you want to edit. Supported formats include `.json`, `.zip`, and `.eln`.
4. Review the existing metadata in the **Entity Editor**.
5. Modify the desired metadata, for example the crate name or description.
6. Click **Save** to store your changes.
7. Optionally inspect the **Metadata Graph** to verify that the changes have been applied successfully.


**Servings**: 
An updated RO-Crate with your changes reflected in the metadata.

- [**Adding Files to a Crate**](recipe-add-files.md)
