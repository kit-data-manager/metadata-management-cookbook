# Adding Authors to a Crate

**Description**:
This recipe guides you through adding author information to a RO-Crate.

**Ingredients**:

- Existing or newly created RO-Crate
- Author details (name, identifier, optional ORCID)
- Access to the NovaCrate web application
- Web browser

**Steps**:

1. Open your crate in [NovaCrate](https://novacrate.datamanager.kit.edu/editor).
2. Click **Add new Entity**.
3. Select **Person** from the *Contextual Entities*.
4. Create the Person entity either by:
   - entering the author's metadata manually and selecting **Create**; or
   - importing the author's metadata directly from ORCID and selecting **Import**. 
5. Select the dataset crate root.
6. Select **Add Property** to add a new property and search for **author**.
7. Click **Link** on the newly created **Author** property and select the Person entity you created.
8. Open the **Metadata Graph** to verify that the author is linked to the crate.
9. Click **Save** to store your changes.

**Servings**:
A RO-Crate containing author metadata linked to the research object.
