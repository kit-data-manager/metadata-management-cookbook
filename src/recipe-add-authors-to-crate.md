# Adding Authors to a Crate

**Description**:
This recipe guides you through adding author information to an RO-Crate.

**Ingredients**:

- Existing RO-Crate: this can be your own RO-Crate or one created by following the [**Creating a new Crate**](recipe-create-new-crate.md) recipe.
- Web browser.
- Access to the NovaCrate web application.

**Steps**:

1. Open the RO-Crate in [NovaCrate](https://novacrate.datamanager.kit.edu/editor) by following steps 1–3 of the [**Editing an Existing Crate**](recipe-edit-existing-crate.md) recipe.
2. Click **Add new Entity**.
3. Select **Person** from the *Contextual Entities*.
4. Create the Person entity either by:
   - importing the author's metadata directly from ORCID and selecting **Import**; or
   - entering the author's metadata manually and selecting **Create**.
5. Select the dataset crate root.
6. Select **Add Property** and search for **author**.
7. Click **Link** on the newly created **Author** property and select the Person entity you created in step 4.
8. Open the **Metadata Graph** to verify that the author is linked to the crate.
9. Click **Save** to store your changes.

**Servings**:
An RO-Crate containing author metadata linked to the research object.
