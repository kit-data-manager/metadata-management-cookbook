# Introduction to NovaCrate

**Description**:

NovaCrate is a browser-based editor for creating, editing, visualising, and validating Research Object Crates (RO-Crates). It helps researchers package data, metadata, and contextual information in a structured and reusable format.

**Ingredients**:

* Access to the NovaCrate web application
* Web browser

**Steps**:

1. Open the [NovaCrate](https://novacrate.datamanager.kit.edu) web application.
2. Click **Open NovaCrate**.
3. Select **Quickstart** from the main menu.
4. Open one of the example RO-Crates provided.
5. Review the metadata entities in the **Entity Editor**.
6. Use the tools available in the left-hand navigation panel to:

   * open the **File Explorer** and browse the crate contents;
   * open the **Metadata Graph** and visualise the relationships between entities;
   * open the **JSON Editor** and inspect the crate metadata in JSON-LD format.
   * open the **Context Editor** and check the RO-Crate specification used by the example.
