# Adding Files to a Crate

**Description**:
This recipe guides you through adding research files to an existing RO-Crate using NovaCrate.

**Ingredients**:

- Existing RO-Crate: this can be your own RO-Crate or one created by following the [**Creating a new Crate**](recipe-create-new-crate.md) recipe.
- Access to the NovaCrate web application.
- Web browser.

**Steps**:

1. Open the RO-Crate in [NovaCrate](https://novacrate.datamanager.kit.edu/editor) by following steps 1–3 of the [**Editing an Existing Crate**](recipe-edit-existing-crate.md) recipe.
2. Click **Add new Entity**.
3. Select **File** from the *Data Entities*.
4. Choose the file you want to upload.
5. Click **Create**.
6. Review the generated metadata for the newly added file in the **Entity Editor**.
7. Open the **File Explorer** to locate and browse the uploaded file.
8. If the file format is supported, you may now double-click the file to preview its contents.
9. Open the **Entity Graph** to inspect how the file is represented within the crate.
10. Click **Save** to store your changes.

**Servings**:
An RO-Crate containing a research file and its corresponding metadata.

You may now continue with:

* [**Adding Authors to a Crate**](recipe-add-authors-to-crate.md)
* [**Editing an Existing Crate**](recipe-edit-existing-crate.md)
